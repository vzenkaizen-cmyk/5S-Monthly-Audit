📋 5S Audit Management System

A simple web-based system for conducting and managing 5S audits efficiently.

✨ Features
📝 Section-wise 5S audit scoring
📊 Real-time overall score
💾 Save and create new audits
📥 Export audits to Excel & Word
🗑️ Delete audits
🚦 Overall audit status indicator
🏆 5S Audit Sections
👔 Leadership
📦 Seiri – Sorting
🗂️ Seiton – Organisation
🧹 Seiso – Cleanliness
📏 Seiketsu – Standardisation
🎯 Shitsuke – Self-Discipline
⚡ Productivity / Services
✅ Quality
💰 Cost
🚀 Run Locally

Open index.html in a browser or use VS Code Live Server.

🌐 Deployment

The system can be deployed using GitHub Pages or another static web-hosting platform.

🎯 Purpose

To make 5S auditing simple, structured, efficient, and easy to report.
